# Contributing

Thank you for your interest in VibeQuarters.

This project takes **issues only**. Pull requests from outside the project are not reviewed or merged, and may be closed without comment. This keeps the review burden small and every line of code traceable to the maintainers.

## How to help

- **Bug reports.** Open an issue with your operating system, your Node.js version (`node -v`), your Claude Code version (`claude --version`), what you did, what you expected, and what happened. If the server printed an error, include it. Remove any names, paths, session text or keys before you paste anything.
- **Install problems.** These are the most useful reports. Say which step of the README failed.
- **Feature ideas.** Open an issue that describes the problem you want solved, not only the solution.
- **Security problems.** Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Before you file

- Try `npm run demo`. If the demo works and your real setup does not, say so: it narrows the problem down.
- Run the tests with `npm test` and include any failure.
