Leave plan mode and carry out the approved plan with whichever tools it needs. $ARGUMENTS

- If no plan was written, or the user has not approved it, ask for `/plan <task>` and stop there.
- Small details can be settled as you go. If the files, the order or the method would have to change, describe the
  difference in a few sentences and wait.
- Give a one-sentence update when a step is complete.
- At the end, list what is different now, what remains and what the user should check.
